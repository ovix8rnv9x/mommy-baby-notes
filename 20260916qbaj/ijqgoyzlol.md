# 雪糕，你家孩子吃“对”了吗？

> 更新时间：2026-09-16 (UTC+8)

// 

今年夏天，网络上出现一个新的流行语——**“雪糕刺客”**

深刻地告诉我们不认识的雪糕不要拿，不然会变得“不幸”

毕竟，你永远不知道超市冰柜里不起眼的雪糕价格有多离谱。除了价格，另一个打消许多家长购买念头的原由，那就是——孩子那么小，吃雪糕会不会伤到脾胃？孩子那么小，吃雪糕会不会伤到脾胃？

**
**

**那么小朋友到底能不能吃雪糕呢？什么时候能吃？又该怎么挑选？孩子多大能吃雪糕？**

  //  

**敲黑板：孩子1岁以下，绝对不能吃！**

绝大部分市售雪糕都含有糖类，少部分在加工中还会添加盐。1岁以内的宝宝建议以母乳或者配方奶喂养，天然食物做辅食。我国居民膳食指南建议2岁以内孩子的辅食中不添加糖，所以在宝宝1至2岁的期间，尽量不要给孩子吃市场上的雪糕，可以自制少糖的雪糕。

**孩子2岁以后可以吃雪糕，尽量也不要主动提供！！**

因为雪糕的成分基本上是高糖、高油、高热量，2岁以上孩子每天葡萄糖摄入量最好不要超过25克。

没看错，就是这么一捏捏

**为什么吃雪糕会拉肚子？**

  //  

虽然孩子2岁后可以偶尔吃一次雪糕，但是，确实也有很多孩子甚至成人，在吃完冰冷的食物后，会多少出现不舒服的反应，比如腹痛、腹泻等。其实，有时吃完冷食会不舒服，未必是“冰冷”造成的，也可能存在以下原因：

1、食物被病菌污染

吃完雪糕会腹泻，有较大的可能是食物已经被病菌污染了。如果食物材料存储不合理，食物制作时卫生不合格，所用厨具与生食接触……都有可能造成孩子腹痛、腹泻。

2、食物过敏或不耐受会

对孩子来说，食物过敏也是引起肠胃不适的一大原因。夏天吃的冷食里，常常会有添加牛奶、芒果、菠萝等易致敏食物。除了过敏，还有可能是食物不耐受。有些孩子的肠胃不能消化分解某些特定食物，就会引起胀气、腹泻、腹痛等不适症状。

3、一次性吃太多

大热天吃雪糕多舒服啊，所以孩子一不小心就容易吃多。有时其实无关温凉，吃多了都容易引起消化不良。

4、个人体质

有些孩子天生肠胃比较脆弱，比如有肠易激综合症的、容易得肠胃炎的，吃冷食就可能引起肠胃不适。雪糕刚吃进去或是吃得很快时，会使胃部血管收缩，降低消化液的分泌和胃肠蠕动速度，短时间内会影响到消化功能。

**如何选择雪糕？**

  //  

选雪糕除了看价格，一定要看配料表。要关注配料表中的先后顺序。一般的食品配料是按照由多到少的顺序排列的，越靠前含量越多。如果配料表中奶或奶制品排在前几位的，那么产品中的含奶量就比较有保证。

根据我国《冰冻饮品 冰淇淋》推荐标准GB/T31114-2014，冰淇淋大致分为全乳脂、半乳脂和植脂三种类型。“全乳脂冰淇淋”是指主体部分乳脂质量分数为8%以上（不含非乳脂）的冰淇淋。意思是，冰淇淋里的脂肪成分全来自乳，且乳脂在整个冰淇淋里至少占到8%。如果乳脂含量≥2.2%，同时＜8%，那这款冰淇淋就是“半乳脂冰淇淋”。如果乳脂含量降到2.2%以下了，就是“植脂冰淇淋”了。

但是，如果配料中含有“植脂末”就要提高警惕了！植脂末也就是反式脂肪酸，对人体危害很大，容易形成血栓，影响孩子发育，影响生育，降低记忆，更容易使人发胖，世界各国对它都是严格控制。

为避免反式脂肪酸的“隐形”积累，尤其是成长发育中的幼儿及少年，建议家长不要让孩子经常食用配方中含有植脂末、人造奶油、植物奶油、起酥油等成分的雪糕或冰激凌。

最重要的，一定要购买正规产品。购买的时候要看好生产日期和保质期，不合格的冷饮，会存在微生物超标，影响家人健康。

总的来说，从饮食或营养角度，任何健康风险或收益都是长期积累的过程，如果孩子只是偶尔吃一次雪糕，家长不用特别纠结。
