# 不远百里 生命之托 以诚相报——我院专家赴基层医院完成复杂食道异物取出术一例

> 更新时间：2026-09-16 (UTC+8)

近日，我院耳鼻咽喉科陈红耀主任医师赴晋州市人民医院重症室，成功为一位食道异物伴纵隔脓肿的病危患者完成复杂食道异物取出术。

患者为65岁男性，孤寡老人，1个多月前误咽枣核，当时颈部疼痛，仅可进食半流食，因未婚、无子女且经济条件差，故未诊治。1个月后患者突发胸痛及高热症状，被亲属急送某三甲医院，诊断为“食道主动脉弓水平异物，纵膈脓肿，低蛋白血症”，因病情危险、复杂，将患者收入该院ICU，拟待病情相对稳定后再行进一步治疗。但因住院费用高，患者及家属难以承受，故转回所在地医院ICU治疗。

1

患者家属多方打听，因该村曾有3名村民于我院耳鼻咽喉科行食道异物手术，术后均恢复非常好，故患者家属专程来我院与陈红耀主任医师联系。在认真听取病史及分析相关资料后，陈红耀主任医师告知家属，患者目前高热、纵膈脓肿及低蛋白均与食道异物有关，又因异物与主动脉弓紧邻，且周围已有脓肿形成，随时有可能主动脉等周围大血管破裂出血致死，应尽早手术治疗。但异物位置紧贴主动脉弓，术中发生主动脉破裂导致患者死亡风险极高。

患者家属充分相信我院及陈红耀主任医师，并表示共担风险，请陈红耀主任医师为患者手术。因患者当时病危状态，不宜转院，经我院医务处与晋州市医院协调联系后，陈红耀主任医师赴晋州市人民医院ICU，张赛医师作为助手，调用我科最好的食道镜及器械，在ICU医护人员配合下，顺利完成了食道异物取出术，整个手术过程约10分钟，术中完整取出枣核一枚，未造成副损伤。

术后经过抗感染及补液支持等治疗，目前患者病情平稳，已转至普通病房，不日即将出院。 术后患者家属及乡亲数十人在ICU门外等候，一定要给陈红耀主任医师5000元手术费作为感谢，被婉言拒绝，家属感动得热泪盈眶。

专家提醒您 吃“枣”小贴士

1. 细嚼慢咽

吃粽子时要细嚼慢咽，慢慢品尝食物的美味，小心误咽枣核。

2. 食不言寝不语

吃饭的时候，尽量不要说话，专心吃饭，防止出现误咽枣核的现象；还可以防止误咽食水进气管。

3. 及时来医院就诊

如果不小心误咽枣核，家人要冷静，千万不要吞咽食物去往下压，这样只会使得枣核越压越深，加重食道损伤。要及时把患者送到正规的医院进行治疗，以免耽误病情。

4. 老人尤其要注意

老人因为年纪大、牙口不好或因佩戴假牙导致口腔黏膜反应不够敏感，咽反射也不够敏感；在吃粽子之前，应该把枣核提前摘除，以免发生误吞枣核的现象。

另外，佩戴假牙或牙齿有松动的老人，进食粘性食物时，要小心粘性食物把假牙粘下，一并吞咽。
